Welcome

This is the mesh control surface. An agent binds a handbag (persona + tools) to a model profile and listens on mission topics over the mesh bus. Nothing happens until a message lands on a topic an agent is subscribed to.

Bus topics

No topics have carried messages yet. Send a test message to an agent to create the first topic.

The bus is a durable SQLite-WAL topic log. Each row is a topic with the number of messages it has carried. Use Send test on any agent, or publish manually via the API, to exercise the chain.

Swarm connector

The connector bridges an external platform (Discord, Slack, lollms.com, ...) onto the mesh bus. Without a live connection binding, the connector has nothing to ingest — no external human traffic reaches the mesh, so agents listening on swarm.inbound will remain idle.

You can still exercise the swarm path with Send test message below, which bypasses the platform and injects a message straight onto the ingress topic.

Compose a new agent

An agent binds a handbag (persona, tools, skills, memory) to a model profile and listens on the topics you assign it.

Each topic is a slug (letters/digits/_/-/.), not a sentence. Without at least one topic the agent will start but do nothing.

MCP server

An MCP server lets this agent reach an external service (Gmail, Outlook, IMAP, Postgres, a helpdesk, ...). Without one, a "mail agent" cannot actually read your emails — it can only talk about them from what the model already knows.
