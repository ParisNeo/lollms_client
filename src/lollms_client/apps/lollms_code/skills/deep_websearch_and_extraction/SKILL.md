# Deep Web Searching and Extraction Skill

## Research Protocol
1. **Search Query Formulation**: Formulate diverse, keyword-rich queries avoiding conversational fluff.
2. **Multi-Source Cross-Examination**: Never rely on a single search result. Search across 3-5 distinct sources to verify claims.
3. **Scraping & Content Fetching**: Once search results yield relevant URLs, use web fetching tools to extract clean article text and verify underlying data.
4. **Attribution & Transparency**: Always cite full source URLs, publication dates, and author names when reporting findings.
