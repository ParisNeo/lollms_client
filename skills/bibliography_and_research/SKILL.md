# Bibliography and Research Skill

## Literature Search & Paper Acquisition
1. **Paper Discovery**: When searching for scientific literature, query arXiv or local Zotero libraries if tools are available, or use web research tools with specific academic keywords.
2. **Citation Standards**: Structure bibliographies in standard formats (BibTeX, APA, IEEE, or Chicago) as requested.
3. **BibTeX Extraction**: Maintain clean `.bib` files containing standard entries (`@article`, `@book`, `@inproceedings`) with author, title, journal/booktitle, year, volume, and DOI.

## Synthesis Workflow
- Organize papers chronologically or thematically.
- Extract abstract, core methodology, benchmarks, and limitations for each paper.
- Build comparative markdown summary tables comparing approaches, datasets, and accuracy metrics.
